# Práctica Integradora 1 a 5

1. **Configuración Inicial:**
   - Clonar el repositorio del proyecto `frontend-practica` (interfaz web de la API).
   - Instalar las dependencias y configurar las variables para conectarlo a la `rest-api` local:
     ```bash
     npm install
     echo "VITE_API_URL=http://localhost:3000" > .env
     ```
   - Verificar la comunicación correcta levantando el servidor de desarrollo:
     ```bash
     npm run dev
     ```
     *(Abrir `http://localhost:5173` en el navegador y hacer clic en "Fetch Data" para confirmar que carga)*.

2. **Pruebas Unitarias (Jest):**
   - Ejecutar las pruebas unitarias localmente con `npm run test`.
   - Notar que existe una prueba fallando a propósito en `utils.test.js`.
   - (Opcional) Modificar la función en `utils.js` para corregir el error y volver a ejecutar `npm run test` para verificar el resultado.
   - (Opcional) Asegurar que todas las pruebas pasen y se alcance el nivel de cobertura adecuado.

3. **Construcción:**
   - Escribir un Dockerfile para el frontend y construir la imagen.
   - Etiquetar la imagen con la versión `v1.0.0-practica`.
   - Subir la imagen a la cuenta personal de Docker Hub del estudiante.

4. **Automatización de Pruebas:**
   - Crear un pipeline de CI (GitHub Actions) para el repositorio del frontend.
   - Configurar el pipeline para ejecutar las pruebas unitarias en cada push al branch principal.

5. **Análisis de Código y Vulnerabilidades (CVE):**
   - Integrar SonarCloud en el pipeline para analizar la calidad del código del frontend.
   - Añadir un paso para escanear la imagen de Docker usando Trivy.
   - Configurar el escáner para que falle el pipeline si detecta vulnerabilidades con severidad `CRITICAL`.
   - Exportar los resultados del análisis como artefactos.

**Entregable:** Enlace al repositorio del frontend con el pipeline ejecutado de manera exitosa y conectado a SonarCloud.
